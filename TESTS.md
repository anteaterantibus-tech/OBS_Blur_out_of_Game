# Тесты этапа 1 (09.10.2026)

Стенд: portable OBS 32.2.2 (официальный ZIP, SHA256 сверен), Windows 11 x64.
Анализ кадров записи: ffmpeg 9.0.2 + средний цвет и резкость (дисперсия
лапласиана) кадра.

## RUN (выполнены)

1. **Загрузка модуля**: portable OBS стартовал, в логе
   `Loading module: obs-privacy-guard.dll` и
   `[obs-privacy-guard] loaded (version 0.1.0)`, ошибок плагина нет.
   Сцена `TestScene` загрузилась: `source: 'Red'` + `filter: 'Guard'`.
2. **Сквозная запись A/B/C**: фокус на notepad -> RED (t=1..8.5);
   фокус на проводнике + блокнот свернут -> BLACK (t=10..14.5, закрытие
   без задержки); возврат в notepad -> RED (t=16+, восстановление после
   задержки). Фокус в каждой фазе проверен через `GetForegroundWindow`.
   Файл `2026-10-09 18-41-21.mp4`, 1280x720@30.
3. **Fail-closed на старте**: в первом прогоне кадры до появления процесса
   в фокусе были черными.
4. **Изолированный тест focus-watch** (`fwtest.exe`): фокус на notepad ->
   `focused=1`; сворачивание -> `focused=0`; несуществующий процесс ->
   `exists=0, focused=0`. Найден и исправлен баг: `GetModuleBaseName`
   требует `PROCESS_VM_READ` и возвращал пустую строку, заменен на
   `QueryFullProcessImageNameW` (достаточно `QUERY_LIMITED_INFORMATION`).
5. **Лаги рендера**: строк `rendering lag` в логе записи нет.
6. **Список игр (0.2.0)**: сцена `Red` + `process_list=notepad.exe+mspaint.exe`.
   Фокус на notepad -> RED, фокус на mspaint -> RED без изменения настроек,
   фокус на проводнике -> BLACK. Запись `2026-10-09 19-07-37.mp4`.
7. **Размытая шторка (0.2.0)**: сцена с image_source (тестовая мишень
   1280x720) + `shutter_mode=blur`, сила 8. Фокус на notepad -> резкость
   ~22400 (четкая мишень), процесс notepad завершен -> резкость ~438
   (размытая мишень, средний серый, не черный), notepad снова запущен ->
   резкость ~22400. Запись `2026-10-09 19-16-43.mp4`. По пути найдены и
   исправлены две ошибки: в шейдере не хватало объявления `ViewProj`
   (OBS подставляет матрицу только при явном `uniform float4x4 ViewProj`),
   при незагруженном шейдере фильтр корректно ушел в непрозрачную заглушку.
8. **Контроль захвата экрана**: чистый monitor_capture без фильтра в этой
   сессии тоже пишет черный кадр (дупликатор ничего не отдает), поэтому
   размытие проверялось на image_source, а не на display capture.
9. **Объединение источников списка (0.2.1)**: ручной список пуст,
   `process_file=C:\Windows\notepad.exe`, `process_running=mspaint.exe`.
   Фокус на notepad -> RED, на mspaint -> RED, на проводнике -> BLACK.
   Запись `2026-10-09 19-29-19.mp4` (удалена после анализа).
10. **Диагностика черного экрана вместо размытия**: шейдер и эффект в порядке
    (файл на месте, ошибок компиляции в логе нет). Черный вместо размытия
    означает отсутствие входного кадра (карта без сигнала) либо ручную
    шторку (в логе `manual shutter closed`): размывать нечего, срабатывает
    непрозрачный запасной вариант. Проверка: выключить фильтр глазком,
    если карта тоже черная, сначала запустить игру.
11. **Полноэкранная эвристика (0.3.0)**: проверена изолированным тестом
    только чтением, без создания окон и смены фокуса. Живое окно
    1936x1048 при мониторе 1920x1080 корректно опознано как НЕ полный экран,
    несуществующий процесс дал `exists=0`, эвристика ложно не сработала.
    Сквозной тест с настоящим полным экраном NOT RUN: отложен по просьбе
    пользователя, чтобы тесты не перекрывали экран во время работы.
12. **Скан папки игр (0.4.0)**: изолированный тест на временном дереве:

13. **Живое применение настроек (0.4.0)**: убран флаг DEFER_UPDATE.
    Причина жалоб "сила размытия/выбор игры/тип плашки ничего не меняют":
    настройки применялись только по кнопке Закрыть, а смотрели на

14. **Маски (0.5.0)**: сцена красного источника + плашка на левой половине:

15. **Оверлей и эвристика (0.6.0)**: изолированные тесты только чтением.
    `overlay_visible(GameOverlayUI.exe)=0`, пустой список=0.

    дорисовывается в кадр игры. Рабочие пути: ручная шторка и маски

## NOT RUN (не выполнены)

- Alt+Tab и быстрые переключения туда-обратно (покрыты частично фазами B/C).
- Ручная шторка горячей клавишей и возврат в игру при ручном закрытии
  (требует UI/нажатия клавиши).
- Неправильный процесс в настройках плагина (покрыт на уровне fwtest).
- Отсутствие входного кадра и ошибка шейдера (только ревью кода: оба пути
  рисуют заглушку).
- Перезапуск OBS с сохранением настроек.
- Перемещение/масштаб/обрезка источника (актуально с этапа 2, масок нет).
- Перекрывающиеся маски (этап 2).
- Стрим/виртуальная камера (проверена только запись; путь рендера общий).
- Производительность 1080p60 (запись шла 1280x720@30; нагрузка фильтра -
  один сплошной quad, измерение отложено до этапа 2 с размытием).

## Известные ограничения этапа 1

- Режим "закрывать только при сворачивании/закрытии" не реализован (только
  "при любой потере фокуса").
- Второго триггера на сворачивание как отдельного режима нет; сворачивание
  покрывается потерей фокуса.
- Статус в окне свойств статичен (обновляется при открытии диалога).
- Запуск `obs64.exe` не из своего каталога дает ошибку
  `Failed to find locale/en-US.ini` (особенность OBS 32, не плагина).
